悬停交互分解

3D 倾斜 鼠标移入时，卡片跟随光标做 X/Y 轴旋转（-8°~8°），有立体感
反光扫射 一道光从左到右扫过卡片表面，类似 CD 反光效果
色散 光扫过时产生彩虹色散效果（红→黄→绿→青→紫）
边框发光 悬停时边框亮度增强，带渐变色
过渡 所有效果 0.3s~0.6s ease-out 过渡，流畅自然

实现方式

使用 Framer Motion 的 useMotionValue + useTransform 监听鼠标位置，驱动卡片的 rotateX/rotateY 和光晕位置。色散效果使用 CSS background: linear-gradient + clip-path 实现。
