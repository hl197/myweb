推荐两种方案

基于你的需求，以下是两种实现路径

方案 A：Next.js + Tailwind + 动效库（推荐）

技术栈
Next.js (App Router) + Tailwind CSS + Framer Motion + TypeScript

优势

  • Tailwind 暗色主题开箱即用，开发极快
  • Framer Motion 滚动动画一行代码搞定
  • 组件化开发，后续扩展方便

劣势

  • 需要了解 Tailwind 语法
  • 依赖稍多

方案 B：Next.js + CSS Modules + 原生动画

技术栈
Next.js (App Router) + CSS Modules + Intersection Observer + TypeScript

优势

  • 零额外依赖，完全掌控样式
  • 更轻量的最终产物
  • 纯 CSS 实现暗色主题

劣势

  • 需要手写更多 CSS
  • 动画需要自己实现
  • 开发速度稍慢
