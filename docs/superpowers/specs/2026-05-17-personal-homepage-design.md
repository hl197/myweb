# 个人主页设计方案

## 概述

单页滚动个人主页，科技感暖色亮色粒子光子风格，展示个人信息、技能、项目、经历和兴趣。

## 技术栈

- **框架**: Next.js (App Router) + TypeScript
- **样式**: Tailwind CSS
- **动画**: Framer Motion (3D 卡片倾斜、滚动动画)
- **部署**: 静态导出 (static export)，可部署到任意静态托管

## 页面结构

### 导航栏

- 固定顶部，左对齐
- 左侧显示姓名/Logo
- 导航项：首页、技能、项目、时间线、兴趣
- 毛玻璃背景 (backdrop-filter: blur)
- 点击平滑滚动到对应区块
- 当前区块高亮，滚动时自动更新
- 向下滚动时自动隐藏，向上滚动时重新出现

### 内容版块

#### 1. Hero / 个人名片

核心交互组件：

- **个人卡片**：包含头像（渐变发光边框）、姓名（渐变文字）、一句话简介
- **3D 倾斜**：鼠标移入时，卡片跟随光标做 X/Y 轴旋转（-8°~8°），使用 Framer Motion 的 useMotionValue + useTransform
- **反光扫射**：一道光从左到右扫过卡片表面，类似 CD 反光效果
- **彩虹色散**：光扫过时产生彩虹色散效果（红→黄→绿→青→紫），使用 CSS linear-gradient + opacity 过渡
- **边框发光**：悬停时边框亮度增强，带渐变色

#### 2. 技能

- 分类展示：前端 / 后端 / 工具
- 每类一个彩色标识（青/紫/金）
- 标签样式：圆角边框 + 半透明背景 + 彩色边框
- 悬停时发光增强，轻微上浮
- 滚动进入视口时标签逐个淡入

#### 3. 项目

- 两列卡片网格
- 每张卡片包含：编号、项目名称、描述、技术标签
- 卡片边框颜色交替（青/紫）
- 悬停时边框发光 + 轻微上浮
- 点击可跳转到项目链接

#### 4. 经历时间线

- 垂直时间轴
- 左侧发光圆点作为节点（青/紫交替）
- 轴线渐变色：青 → 紫 → 透明
- 条目：时间段 + 标题 + 描述
- 滚动进入视口时条目从左侧滑入

#### 5. 兴趣

- Emoji + 文字的小卡片，轻松有温度
- 与前面科技感版块形成反差
- 悬停时发光增强，轻微上浮

## 视觉规范

### 色彩

| 用途           | 色值                  |
| -------------- | --------------------- |
| 背景色         | `#faf5eb`（暖白米色） |
| 主色（橙）     | `#f97316`             |
| 辅色（紫）     | `#d946ef`             |
| 绿色（技能类） | `#10b981`             |
| 文字主色       | `#1a1a2e`             |
| 文字次级       | `#6b7280`             |
| 卡片背景       | `#ffffff`             |

### 粒子光子效果

- 暖白米色底色上点缀暖色粒子（橙/金），透明度较低
- 保留光子线条，颜色适配暖色系
- 关键文字渐变发光（橙→紫）
- 卡片使用暖色阴影代替发光边框

### 字体

- 中文：系统无衬线字体
- 代码/技术元素：等宽字体 (monospace)

## 交互动画

| 触发         | 效果                   |
| ------------ | ---------------------- |
| 页面加载     | 粒子背景启动，卡片淡入 |
| 滚动到版块   | 内容元素逐个滑入/淡入  |
| 悬停卡片     | 3D 倾斜 + 反光色散     |
| 悬停标签     | 发光增强 + 上浮        |
| 悬停项目卡片 | 边框发光 + 上浮        |
| 导航点击     | 平滑滚动到目标版块     |

## 文件结构

```
src/
  app/
    layout.tsx        # 根布局（全局样式、字体）
    page.tsx          # 主页面（组装各版块）
    globals.css       # 全局样式、Tailwind 基础
  components/
    Navbar.tsx         # 导航栏
    HeroCard.tsx       # 个人卡片（3D 倾斜 + 光效）
    SkillsSection.tsx  # 技能版块
    ProjectsSection.tsx# 项目版块
    TimelineSection.tsx# 时间线版块
    InterestsSection.tsx# 兴趣版块
    ParticleBackground.tsx # 粒子背景
  data/
    profile.ts        # 个人信息数据
    skills.ts         # 技能数据
    projects.ts       # 项目数据
    timeline.ts       # 时间线数据
    interests.ts      # 兴趣数据
```

## 数据流

所有个人数据集中在 `src/data/` 目录，组件通过 import 引入数据。数据变更只需修改对应数据文件，无需改动组件逻辑。
